# Lost Codex Atlas

Static Wynncraft territory planner for Lost Codex [CODX]. No backend, build step, API key, or database is required.

Shift + right-click a territory to edit. Changes save in the browser and compressed URL fragment. Use Map menu → Copy plan link to share the full setup. Export plan / Import plan supports JSON backups. Download static HTML embeds the current setup in a portable page.

The default Ragni claim includes 43 CODX territories. Defence and treasury tiers color the dashed borders and interior fills. Terrain and optional public API refreshes require internet. Saved claims remain available when refreshes fail.

Data and artwork: [Wynncraft API](https://docs.wynncraft.com/), [Wynnmap](https://github.com/Zatzou/wynnmap), [Wynntils Static-Storage](https://github.com/Wynntils/Static-Storage). Economy reference and item sprites: [fa.rog Economy Simulator](https://fa-rog.github.io/economy/). Embedded Monocraft font is licensed under SIL OFL 1.1, included in the HTML. Independent fan project; planning does not change in-game data.
